02 / The editor

Live, in the room.

A split editor with a real browser preview. Save early, save often — or let autosave do it while you chase a keyframe. Nothing is compiled, minified, or hidden behind a proprietary layer.

  • Any CDN, any library. GSAP, Three.js, Lenis, a font you love. We don’t get in the way.

05 / What we believe

No drag handles. No app store. No page like everyone else’s.

We built the opposite of a template factory. Then we added templates, because not everyone wants to write CSS at 1am.

01

Your markup stays yours.

Code pages export as a single HTML file. Templates are a starting point, not a lease. Nothing here is encrypted or trapped behind a plan.

02

Sandboxed by default.

Custom code runs with an opaque origin and no access to cookies or other people’s pages. Your experiments stay experiments, safely.

03

Fewer features, done properly.

No booking widget, no dropshipping app, no AI copy generator. A page, an editor, uploads and a link. That is the product.

06 / Questions

Ask us
anything.

The honest answers, including the parts where we say “not yet.” If your question is missing, the code guide goes deeper into the technical side.

Read the code guide
Can I really write all of my own code?

Yes. HTML, CSS and JavaScript in three panes, with a live preview. You can import any library from a CDN — motion, canvas, WebGL, a font you like — and use whatever markup you want. There is no visual editor in the way.

The one boundary is server-side code. Pages are static, so there is no PHP, Python or database behind your site. For forms, use a third-party endpoint or a mailto link.

What if I can’t code?

Use a template. You fill in a headline, a short bio, projects and links; the template handles layout, type and mobile. Four templates share the same content, so you can switch the look whenever you like without retyping anything.

Can I use my own domain?

Not during the beta. Your page lives at /p/your-address, and your profile at /u/your-name. Custom domains are the first thing on the list after we leave beta. We would rather do them properly than ship a broken redirect.

Can I take my page somewhere else?

Custom-code pages download as one self-contained HTML file from the editor. Host it on Netlify, GitHub Pages, Vercel, or a folder on your desktop. Template pages are rendered by Portside, so they do not export as a single file yet — that is on the roadmap.

What isn’t allowed?

No malware, phishing, harassment, stolen work, or content that is illegal where you live. Custom code runs in a sandbox, but “it can’t read my cookies” is not a moderation policy. Pages can be reported and taken down.

How do view counts work?

One view per visitor session per day, counted on the server. No Google Analytics, no pixels, no cookie banner. The number is a rough signal of interest, not a growth metric.

Why is it free?

Because the beta is small and the hosting bill is smaller. Limits keep it that way: four pages, 5 MB images, modest code size. If we add a paid plan later, there will be a free tier, plenty of notice, and no hostage situations.
